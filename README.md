# P3_ex2 - Multimedia Pokémon

## Com executar-lo

    npm install
    ng serve

Després obre http://localhost:4200

## Compatibilitat amb Can I Use

- WebP és compatible amb els navegadors moderns.
- Àudio: OGG com a primera opció i MP3 com a alternativa, perquè l'MP3 funciona a tots els navegadors.
- Vídeo: WebM com a primera opció i MP4 com a alternativa, pel mateix motiu.
